# 1065 - Even Numbers Among Five

**Plataforma:** Beecrowd
**Dificuldade:** Iniciante
**Link:** https://judge.beecrowd.com/pt/problems/view/1065

## Descricao

Le 5 inteiros e conta quantos sao pares.

## Resultado

| Linguagem | Status   |
|-----------|----------|
| C++       | Accepted |
| Java      | Accepted |
| Python    | Accepted |

## Logica

For de 5 iteracoes, checa n % 2 == 0 pra ver se eh par. Bem direto, so conta e imprime.

## Java vs C++ vs Python

Nenhuma diferenca relevante. A verificacao de par com modulo funciona igual nas tres. So muda a funcao de saida.
