# 1002 - Area of a Circle

**Plataforma:** Beecrowd
**Dificuldade:** Iniciante
**Link:** https://judge.beecrowd.com/pt/problems/view/1002

## Descricao

Le o raio e calcula a area do circulo com A = pi * R^2. Saida com 4 casas decimais.

## Resultado

| Linguagem | Status   |
|-----------|----------|
| C++       | Accepted |
| Java      | Accepted |

## Logica

Formula direta. Nao tem espaco entre "A=" e o valor. Saida com %.4f.

## Java vs C++

Pi em Java vem do Math.PI e em C++ do acos(-1.0). Nos dois a saida usa printf com %.4f.
