# 1143 - Quadrado e ao Cubo

**Plataforma:** Beecrowd
**Dificuldade:** Iniciante
**Link:** https://judge.beecrowd.com/pt/problems/view/1143

## Descricao

Le um inteiro N e imprime N linhas. Cada linha contem o numero i, o seu quadrado e o seu cubo, separados por espaco.

## Resultado

| Linguagem | Status   |
|-----------|----------|
| C++       | Accepted |
| Java      | Accepted |
| Python    | Accepted |

## Logica

Loop de 1 a N imprimindo em cada iteracao i, i*i e i*i*i na mesma linha separados por espaco.

## Java vs C++ vs Python

Identico nos tres. Apenas tres valores calculados por linha. Java concatena String, C++ usa `cout` encadeado, Python usa f-string.
