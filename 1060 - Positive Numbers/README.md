# 1060 - Positive Numbers

**Plataforma:** Beecrowd
**Dificuldade:** Iniciante
**Link:** https://judge.beecrowd.com/pt/problems/view/1060

## Descricao

Le 6 valores (podem ser decimais) e conta quantos sao positivos. Imprime a quantidade seguida de "valores positivos".

## Resultado

| Linguagem | Status   |
|-----------|----------|
| C++       | Accepted |
| Java      | Accepted |
| Python    | Accepted |

## Logica

Um for de 6 iteracoes, le o valor e incrementa o contador se for maior que zero. No final imprime o total.

## Java vs C++ vs Python

O Java precisa de Locale.US no Scanner pra ler decimais com ponto. No C++ o cin ja resolve. Python usa float(input()) direto.
