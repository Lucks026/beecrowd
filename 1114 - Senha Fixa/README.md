# 1114 - Senha Fixa

**Plataforma:** Beecrowd
**Dificuldade:** Iniciante
**Link:** https://judge.beecrowd.com/pt/problems/view/1114

## Descricao

Le valores inteiros repetidamente. Para cada valor diferente de 2002, imprime "Senha Invalida". Quando le 2002, imprime "Acesso Permitido" e encerra.

## Java vs C++ vs Python

Java e C++ aproveitam a leitura na condicao do while. Python usa loop infinito com break ao acertar a senha. Mesma logica simples de comparacao.
