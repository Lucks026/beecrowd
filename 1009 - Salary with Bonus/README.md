# 1009 - Salary with Bonus

**Plataforma:** Beecrowd
**Dificuldade:** Iniciante
**Link:** https://judge.beecrowd.com/pt/problems/view/1009

## Descricao

Le nome, salario fixo e vendas. Bonus eh 15% das vendas. Imprime o total com R$ e 2 casas decimais.

## Logica

Total = salario + vendas * 0.15. O nome eh lido mas nao aparece na saida.
