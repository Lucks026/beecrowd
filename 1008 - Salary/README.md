# 1008 - Salary

**Plataforma:** Beecrowd
**Dificuldade:** Iniciante
**Link:** https://judge.beecrowd.com/pt/problems/view/1008

## Descricao

Le numero do funcionario, horas trabalhadas e valor por hora. Imprime o salario com U$ e 2 casas decimais.

## Resultado

| Linguagem | Status   |
|-----------|----------|
| C++       | Accepted |
| Java      | Accepted |
| Python    | Accepted |

## Logica

Multiplicacao direta de horas por valor/hora. Atencao no prefixo U$ na saida, diferente do R$ de outros problemas.

## Java vs C++ vs Python

Em C++ misturei cout e printf. Em Java usei println e printf. Python usa format() pra formatar as 2 casas decimais.
