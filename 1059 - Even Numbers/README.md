# 1059 - Even Numbers

**Plataforma:** Beecrowd
**Dificuldade:** Iniciante
**Link:** https://judge.beecrowd.com/pt/problems/view/1059

## Descricao

Imprime todos os numeros pares de 2 a 100, um por linha.

## Resultado

| Linguagem | Status   |
|-----------|----------|
| C++       | Accepted |
| Java      | Accepted |

## Logica

Um for comecando em 2, indo ate 100, com incremento de 2. Sem entrada, so saida.

## Java vs C++

Praticamente identico nas duas linguagens. So muda a funcao de print. Esse eh o tipo de exercicio que nao tem diferenca real entre elas.
