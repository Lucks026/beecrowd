# 1040 - Average 3

**Plataforma:** Beecrowd
**Dificuldade:** Iniciante
**Link:** https://judge.beecrowd.com/pt/problems/view/1040

## Descricao

Le quatro notas com pesos 2, 3, 4 e 1. Se media >= 7 aprovado, se < 5 reprovado, senao le exame e calcula media final.

## Resultado

| Linguagem | Status   |
|-----------|----------|
| C         | Accepted |
| C++       | Accepted |
| Java      | Accepted |
| Python    | Accepted |

## Logica

A quinta leitura (exame) so acontece se o aluno ficou em exame. Fluxo condicional de entrada.

## Java vs C vs C++ vs Python

Em C++ usei final_ com underscore porque final e palavra reservada. Python nao tem esse problema e fica mais conciso com if/elif/else. Em C, scanf le as quatro notas de uma vez; o resto da logica eh igual.
