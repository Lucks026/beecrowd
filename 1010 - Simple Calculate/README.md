# 1010 - Simple Calculate

**Plataforma:** Beecrowd
**Dificuldade:** Iniciante
**Link:** https://judge.beecrowd.com/pt/problems/view/1010

## Descricao

Le codigo, quantidade e preco unitario de dois produtos. Imprime o valor total.

## Resultado

| Linguagem | Status   |
|-----------|----------|
| C++       | Accepted |
| Java      | Accepted |

## Logica

Quantidade vezes preco unitario pra cada produto, depois soma os dois. A saida exige formato especifico com os campos na mesma linha.

## Java vs C++

Printf nos dois pra controlar o formato com precisao. Locale.US no Java pra ler os precos.
